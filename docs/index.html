Conector Zendesk — Guía de configuración

Última actualización: octubre 2026

¿Qué es y para qué sirve?

El conector Zendesk permite que el agente de Ruvic gestione los tickets de tu mesa de ayuda en Zendesk Support: crear tickets, actualizarlos, comentarlos y buscarlos. Una vez configurado, puedes pedirle cosas como:

  • "Abre un ticket urgente: el cliente ana@cliente.com no puede ingresar al portal."
  • "¿Qué tickets abiertos de prioridad alta hay desde el lunes?"
  • "Agrega una nota interna al ticket 124 y déjalo en pendiente."

Operaciones soportadas:

OperaciónQué hace
ticket.createCrea un ticket con asunto, descripción, prioridad, solicitante y etiquetas
ticket.updateCambia estado, prioridad, agente asignado o etiquetas
ticket.commentAgrega un comentario público o una nota interna
ticket.searchBusca tickets con la sintaxis de búsqueda de Zendesk
ticket.readConsulta un ticket y, opcionalmente, sus comentarios
Este conector escribe en tu mesa de ayuda Crear, actualizar y comentar cambia tickets reales. Los comentarios públicos le llegan por correo al cliente; el agente usa notas internas cuando se le pide.

Prerrequisitos

  • Una cuenta de Zendesk Support (cualquier plan; hay prueba gratuita de 14 días).
  • Acceso de administrador para habilitar el acceso por token en la API.
  • Un agente dedicado para Ruvic, con acceso a los grupos que debe gestionar.

Configuración en el fabricante

Vas a habilitar el acceso por API Token y a generar un token asociado a un agente dedicado.

  1. Crea el agente dedicado.

    En Admin Center → Personas → Miembros del equipo → Agregar usuario, crea un agente (ej. ruvic@miempresa.com) con rol Agente y asígnalo a los grupos que deba atender.

  2. Activa el acceso por token.

    En Admin Center → Apps e integraciones → API de Zendesk → Configuración, activa Acceso por token.

    [ Captura: configuración de la API de Zendesk con el acceso por token activado — reemplazar por assets/img/zendesk-api.png ]
  3. Genera el API Token.

    Pulsa Agregar token de API, nómbralo "Ruvic" y copia el token de inmediato: Zendesk solo lo muestra una vez.

  4. Anota tu subdominio.

    Es la parte antes de .zendesk.com en la URL de tu cuenta (ej. miempresa).

Permisos requeridos

El API Token actúa con los permisos del agente configurado. Principio de mínimo privilegio: usa un agente, no un administrador.

PermisoPara qué lo usa el conector
Rol AgenteCrear, actualizar, comentar y ver tickets de sus grupos
Acceso por token (API)Autenticar las peticiones del conector con correo + token

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta Zendesk y pulsa Configurar. Diligencia el formulario con los valores de la sección anterior:

Campo del formularioValor
Subdominio de ZendeskLa parte antes de .zendesk.com, ej. miempresa
Correo del agenteCorreo del agente dedicado dueño del token
API TokenEl token del paso 3. Se guarda cifrado y no se vuelve a mostrar
Timeout de conexión (segundos)Opcional; 15 segundos por defecto

Guarda y pulsa Probar conexión: la plataforma valida las credenciales y el acceso.

[ Captura: formulario del conector Zendesk en Settings → Conectores — reemplazar por assets/img/zendesk-form.png ]

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder con éxito y la tarjeta debe quedar en estado Configurado.

  2. Prueba mínima con el agente.

    Abre una conversación nueva y pídele:

    "¿Cuántos tickets abiertos hay en Zendesk y cuál es el más reciente?"

    El agente debe responder con tickets reales de tu cuenta. Para probar escritura, pídele crear un ticket de prueba y luego resolverlo.

Solución de problemas

Mensaje / síntomaCausa probable y solución
"Correo o API Token inválidos" (401)El token fue revocado, el correo no es el del dueño del token o el acceso por token está desactivado.
"No existe una cuenta de Zendesk en …"El subdominio está mal escrito. Usa solo la parte antes de .zendesk.com.
"El agente configurado no tiene permiso" (403)El agente no pertenece al grupo del ticket o su rol no permite la acción.
"status 'closed' inválido"Zendesk no permite cerrar tickets por API; márcalo como solved.
"Límite de peticiones alcanzado" (429)Tu plan limita las peticiones por minuto. Espera los segundos indicados.

Preguntas frecuentes y notas de seguridad

¿El cliente recibe los comentarios que agrega el agente?

Sí, si son públicos (el valor por defecto). Pide explícitamente "nota interna" para que no le llegue.

¿Dónde queda guardado el API Token?

Como secreto cifrado en la plataforma. La interfaz no vuelve a mostrarlo.

¿Cómo roto o revoco el token?

Crea uno nuevo en Admin Center → API de Zendesk, actualízalo en el formulario, prueba la conexión y elimina el anterior. Si se compromete, elimínalo de inmediato.
